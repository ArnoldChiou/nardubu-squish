# Nardubu 果凍捏捏

以藍莓冰霜捏捏為靈感的非官方 3D 瀏覽器互動實驗。使用 Three.js 物理材質、透光外膜與 115 塊不規則冰霜內層。

## 玩法

- 用滑鼠按住果凍並拖曳，觀察局部凹陷與內容物位移。
- 捏深後內層逐段錯開、露出裂縫，伴隨即時合成的細碎喀滋聲。
- 放開後慢慢回彈、裂縫漸漸合攏；此為可重玩的視聽模擬，不是實際材料破壞模型。
- 手機支援多點觸控；部分裝置另有震動回饋。
- 鍵盤可聚焦玩具後按空白鍵或 Enter。

## 本機執行

```bash
npm install
npm run dev
```

本專案會透過 GitHub Actions 自動發布至 GitHub Pages。

需要支援 WebGL 2 的瀏覽器。音效需由第一次操作啟用；震動支援依裝置而異。

檢查幾何：`node scripts/check-geometry.mjs`。目前環境未連接互動瀏覽器，視覺、手機實際效能與聽感仍需真人體驗確認。
