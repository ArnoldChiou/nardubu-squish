# Nardubu 果凍捏捏

以藍莓冰霜捏捏為靈感的非官方 3D 瀏覽器互動實驗。使用 Three.js 物理材質、透光外膜與 115 塊不規則冰霜內層。

## 玩法

- 用滑鼠按住果凍並拖曳，觀察局部凹陷與內容物位移。
- 捏深後先裂開 115 塊不規則內層，再依局部損傷分裂為 678 個較細碎片；裂縫擴大、碎片傾斜並往內錯落，外皮保持完整。
- 音效採用約 145 毫秒的乾脆爆裂簇，含短促主裂聲與 7–11 個不規則細碎瞬態；降低低頻摩擦與放手尾音，保留音量限制與靜音。
- 放手保留形狀與裂痕，繼續揉捏會累積形變；按「重新開始」才還原。重新整理頁面也會開始新的一顆。
- 手機支援多點觸控；部分裝置另有震動回饋。
- 鍵盤可聚焦玩具後按空白鍵或 Enter。

## 本機執行

```bash
npm install
npm run dev
```

本專案會透過 GitHub Actions 自動發布至 GitHub Pages。

需要支援 WebGL 2 的瀏覽器。音效需由第一次操作啟用；震動支援依裝置而異。

## 材料模型

162 個表面粒子、480 條 XPBD 距離約束與體積約束，固定 120 Hz 步進。局部接觸驅動形變，近似體積守恆使鄰近區域鼓起；超過屈服應變時改變約束的靜止長度，損傷只累積不癒合。放手鎖定卸載形狀，不使用回到球形的動畫。外皮、脆層、內容物與點擊判定同步實際形變。

這是為網頁即時互動設計的塑性軟體近似，不是經實物材料量測校準的 FEM；未實作完整自碰撞、碎片自由脫落或真實觸覺阻力，極端反覆揉捏仍可能出現不自然折疊。音效依描述合成。

檢查：`node scripts/check-geometry.mjs`、`node scripts/check-physics.mjs`、`node scripts/check-crunch.mjs`。測試涵蓋局部受力、拖曳方向、體積誤差、放手不回復、不可逆分段碎裂、重複揉捏、雙點接觸、手動重置、音訊峰值與頻段能量、靜音及節流。這些程式檢查不等於實際試聽；視覺、手機效能與聽感仍需實機體驗確認。
